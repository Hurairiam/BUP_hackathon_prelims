How it works

  1. You type notes in plain English.
  2. FastAPI sends them to an OpenAI-compatible LLM (Groq / OpenAI / OpenRouter — auto-detected from the key prefix).
  3. Pydantic v2 auto-heals malformed LLM output: hours deduped & clamped, factors clamped, no_op enforced.
  4. PuLP solves a 24-hour linear program: minimise Σ grid[h] · tariff[h] subject to SoC, rate caps, end-of-day neutrality, and directive overlays.
  5. FastAPI recomputes totals, formats an OptimizeResponse, and streams it back here.
